The GEO Audit Agent Skill reviews a site the way an AI assistant reads it, and reports what is stopping it being used as a source.

Traditional SEO audits grade a page against ranking factors. This grades it against *extractability* — whether an assistant can reach the page, parse it, and lift a passage from it with confidence.

## What this skill helps your agent do

- Check the foundations in order: crawler access, then structure, then content.
- Flag pages that rank but are unusable as an AI source, and say why.
- Separate what blocks every assistant from what only affects one.
- Rank findings by how much visibility each one is actually costing.

## When to use it

As the starting point for AI-visibility work, before the narrower skills. It tells you which of them to run next.

## What you get back

A prioritised findings list, each with the evidence behind it and the fix, ordered by impact rather than by category.
