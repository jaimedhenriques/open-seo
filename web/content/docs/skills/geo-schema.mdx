The Structured Data Agent Skill writes and checks JSON-LD so machines can read a page's meaning rather than infer it.

Schema has always helped search engines. It matters more for assistants, which rely on explicit structure to decide what a page is about and whether to trust it.

## What this skill helps your agent do

- Pick the right schema types for the page, rather than stacking every type available.
- Generate valid JSON-LD that matches what is actually on the page.
- Catch markup that contradicts the visible content — a common cause of it being ignored.
- Validate existing markup and report what is malformed or unsupported.

## When to use it

Once crawler access and content structure are sorted; schema amplifies a good page rather than rescuing a weak one.

## What you get back

Ready-to-paste JSON-LD per page, plus a validation report on anything already in place.
